# 파이썬·SQL 전체 복습: 자료구조부터 JOIN까지

**날짜:** 2026-09-04 (금) 오전

---

## 1. 파이썬 인터프리터, 가상환경, uv, VS Code, 주피터 노트북

- **파이썬 인터프리터**: 작성한 파이썬 코드를 한 줄씩 읽어서 컴퓨터가 이해할 수 있는 기계어로 번역하고 실행해주는 프로그램.
- **가상환경**: 프로젝트마다 필요한 파이썬 라이브러리(도구) 버전을 독립적으로 분리해주는 공간. 프로젝트끼리 버전 충돌이 나지 않게 막아준다.
- **uv**: 파이썬 패키지와 가상환경을 빠른 속도로 관리해주는 최신 툴.
- **VS Code / 주피터 노트북**: 코드를 작성하고 실행 결과를 확인할 수 있는 개발 도구(에디터). VS Code는 일반적인 프로그램 개발에, 주피터 노트북은 데이터를 분석하며 한 줄씩 실행하기에 좋다.

## 2. 클래스와 상속

- **클래스**: 붕어빵 틀처럼 속성(데이터)과 기능(함수)을 모아둔 설계도.
- **객체**: 그 설계도를 바탕으로 찍어낸 실물(붕어빵).
- **상속**: 이미 만들어둔 클래스의 기능을 그대로 물려받아서, 새로운 기능을 덧붙이거나 수정하여 코드를 재사용하는 기법.

## 3. 리스트, 튜플, 딕셔너리, 집합(자료구조)

| 자료구조 | 특징 |
|---|---|
| 리스트 `[ ]` | 순서가 있고, 언제든 값을 추가·수정·삭제할 수 있는 가장 흔한 데이터 모음 |
| 튜플 `( )` | 리스트와 비슷하지만, 한 번 만들면 값을 절대 바꿀 수 없는(불변) 데이터 모음 |
| 딕셔너리 `{키: 값}` | 이름표(키)와 내용(값)을 쌍으로 묶어서, 빠르게 찾을 수 있는 데이터 모음 |
| 집합 `{ }` | 순서가 없고 중복된 값을 허용하지 않는 수학의 집합 개념 |

## 4. 조건문과 반복문(제어문)

- **조건문**(`if` / `elif` / `else`): "만약 조건이 맞다면 이 코드를 실행하고, 아니면 저 코드를 실행해"라며 상황에 따라 흐름을 바꾸는 기능.
- **반복문**(`for` / `while`): 똑같은 작업을 코드를 여러 번 쓰지 않고 컴퓨터가 수십, 수백 번 알아서 반복하게 만든다. 데이터를 검색하거나 필터링하는 로직에 활용된다.

## 5. 함수, 변수 스코프, 모듈, 패키지

- **함수와 매개변수/반환값**: 자주 쓰는 코드를 하나로 묶어둔 상자. 상자에 재료를 넣으면(매개변수), 처리를 거쳐 결과를 돌려준다(반환값).
- **변수 스코프**: 변수가 살아 숨 쉬는 유효 범위. 함수 안에서만 쓸 수 있는지, 코드 전체에서 쓸 수 있는지(지역 변수 vs 전역 변수)를 뜻한다.
- **모듈과 패키지**: 파이썬 코드(`.py`) 파일을 모아두면 '모듈', 이 모듈들을 폴더 단위로 모아두면 '패키지'가 되어 코드를 부품처럼 조립해 쓸 수 있다.

## 6. 구문 오류, 런타임 예외, 예외 처리, 디버깅

- **구문 오류(Syntax Error)**: 문법이 틀려서(예: 괄호 누락) 아예 실행조차 안 되는 오류.
- **런타임 예외(Exception)**: 실행은 되지만, 도중에 예상치 못한 문제(예: 0으로 나누기, 없는 파일 열기)를 만나 멈추는 오류.
- **예외 처리**(`try` / `except`): 오류가 나더라도 프로그램이 멈추지 않고 "이런 에러가 나면 이렇게 대처해"라고 안전장치를 걸어두는 것.
- **디버깅**: 코드를 한 줄씩 멈춰가며 에러의 원인을 추적하고 수정하는 과정.

## 7. SELECT 기본 구조

```sql
SELECT column_name   -- 가져올 컬럼(열) 지정
FROM table_name       -- 데이터를 가져올 테이블 지정
WHERE condition        -- 특정 조건을 걸어 원하는 데이터만 필터링
ORDER BY column_name;  -- 조회 결과를 오름차순/내림차순으로 정렬
```

## 8. 다중 테이블 JOIN과 서브쿼리

- **JOIN**: 연관된 여러 개의 테이블을 공통된 기준(고유번호 등)으로 연결하여 한 번에 모아 조회한다.
- **서브쿼리**: 쿼리문 안에 또 다른 쿼리문(하위 쿼리)을 괄호로 품고 있어서, 복잡한 단계의 조건을 처리할 때 사용한다.

## 9. GROUP BY와 집계 함수

- **GROUP BY**: 데이터를 특정 기준(예: 부서별, 상품 카테고리별)으로 묶어준다.
- **집계 함수**: 묶인 그룹 안에서 합계(`SUM`), 평균(`AVG`), 개수(`COUNT`), 최대/최솟값(`MAX`/`MIN`)을 계산해준다.
