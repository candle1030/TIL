# SQL: DDL과 DML

**날짜:** 2026-09-21 (월)

---

## 1. DDL (Data Definition Language)

데이터 테이블의 구조를 정의하거나 변경하는 명령어. 데이터를 넣고 빼는 것이 아니라, 데이터가 들어갈 공간(테이블)의 구조를 만드는 것이다.

| 명령어 | 의미 |
|---|---|
| `CREATE` | 생성 |
| `ALTER` | 구조 변경 |
| `DROP` | 삭제 |
| `TRUNCATE` | 테이블의 데이터 전체 삭제 |

## 2. DML (Data Manipulation Language)

테이블 안의 데이터를 조작하는 명령어.

| 명령어 | 의미 |
|---|---|
| `INSERT` | 데이터 추가 |
| `UPDATE` | 데이터 수정 |
| `DELETE` | 데이터 삭제 |
