## 1. 오늘 배운 것 체크리스트

- `&`(엔드), `|`(오어), `~`(틸드, 부정조건 - ~이 아닌 것)
- `isin()`으로 여러 값 중 하나에 해당하는 행을 선택할 수 있다.
- `sort_values()`로 원하는 기준과 방향으로 정렬할 수 있다.
- 필요하면 `.copy()`로 원본과 작업 데이터를 구분할 수 있다.
- 수량과 단가로 `line_total` 파생 컬럼을 만들 수 있다.
- `value_counts()`, `groupby()`, `agg()`의 역할을 구분할 수 있다.
- `count()`, `size()`, `nunique()`의 차이를 설명할 수 있다.
- groupby 기준 컬럼이 결과 표의 한 행의 의미를 결정한다는 점을 이해할 수 있다.
- `merge()`의 연결 키와 병합 방식을 설명할 수 있다.
- 일대일·일대다·다대일·다대다 관계를 구분할 수 있다.
- `validate`와 `indicator`로 병합 결과를 검증할 수 있다.
- 전체 주문 상세 금액과 완료 주문 기준 매출을 구분할 수 있다.
- 주문상세 행 수와 실제 주문 건수를 구분할 수 있다.
- 카테고리별·상품별·월별·고객별 매출표를 만들 수 있다.
- 결과를 CSV 파일로 저장하고 다시 확인할 수 있다.
- LLM이 작성한 pandas 코드를 실제 데이터 구조와 분석 범위에 맞춰 검증할 수 있다.

## 2. 질문 유형별 판다스 기능 매핑

| 무엇을 볼 것인가 | 컬럼 선택 | `df[...]` |
|---|---|---|
| 어떤 행을 남길 것인가 | 필터링 | 조건식, `isin()` |
| 무엇을 먼저 볼 것인가 | 정렬 | `sort_values()` |
| 새 값을 어떻게 만들 것인가 | 파생 컬럼 | 새 컬럼 대입 |
| 값이 얼마나 반복되는가 | 빈도 | `value_counts()` |
| 그룹별로 어떻게 요약할 것인가 | 집계 | `groupby()`, `agg()` |
| 여러 파일을 어떻게 연결할 것인가 | 병합 | `merge()` |
| 결과를 어떻게 남길 것인가 | 저장 | `to_csv` |

## 3. 데이터프레임 vs 시리즈

```python
customers[["customer_id", "age", "city"]]   # 여러 컬럼 -> 데이터프레임
customers["customer_id"]                    # 컬럼 하나 -> 시리즈
```

- product_id 기준 제품(products)의 전체 개수, order_items 기준 한 번이라도 주문된 제품의 전체 개수를 구분해서 봐야 한다.
- 상품의 가격과 개수를 더한 값은 `line_total`.

## 4. 파생 컬럼 만들기

```python
order_items_work = order_items.copy()
order_items_work["line_total"] = (
    order_items_work["quantity"]
    * order_items_work["unit_price"]
)
```

- `line_total`은 원본 `order_items`에는 없던 컬럼이다.
- `sort_values`는 정렬을 담당한다. 동작을 구현할 때는 메서드를 사용한다.

## 5. 실전에서 만난 에러

```python
df_customers = pd.read_csv(DATA_DIR + "/customers.csv")
df_customers.info()
```
```
TypeError: unsupported operand type(s) for +: 'WindowsPath' and 'str'
```

경로와 파일명을 `+`로 이어 붙이려다 타입 에러가 발생한 경우 — `Path` 객체와 문자열은 `+`로 바로 이어 붙일 수 없고, `/` 연산자나 `os.path.join`을 사용해야 한다.

## 6. 조건식과 불리언 마스크

조건식은 참/거짓을 만든다 — 이를 **불리언 마스크**라고 하며, 참과 거짓을 걸어놓고 거짓은 보이지 않게 가리는 것을 뜻한다.
