# CSS 상속·우선순위·display, JavaScript map(), Next.js Link

## 1. HTML과 CSS의 역할

- **HTML**: 집의 뼈대. 방, 문, 창문이 어디에 있는지 정한다.
- **CSS**: 인테리어. 벽지 색, 가구 크기, 간격처럼 어떻게 보이는지 정한다.

## 2. CSS 상속

부모 요소에 준 스타일을 안에 있는 자식 요소들이 그대로 물려받는 것. 부모가 정한 가족 말투를 아이들이 따라 쓰는 것과 비슷한 개념이다.

```
body  ← color, font-family 지정
 ├─ section.member-card
 │   ├─ h2 (홍길동 회원)     ← 따로 안 줬는데 같은 색·글꼴
 │   └─ p  (이메일)          ← 따로 안 줬는데 같은 색·글꼴
 └─ form#signup-form
     ├─ h3, p                ← 마찬가지
```

## 3. 선택자 우선순위

| 신분 | 코드 | 비유 |
|---|---|---|
| p 태그 | `p` | 전교생 중 한 명 |
| notice 클래스 | `.notice` | 3반 학생 |
| important 아이디 | `#important` | 홍길동이라는 개인 |

> 대상이 넓을수록 약하고, 좁을수록 강하다. 같은 급이면 나중 말이 이긴다.

## 4. display

`display`는 HTML 요소가 화면에서 어떻게 배치되고 공간을 차지할지 결정하는 CSS 속성이다.

| 값 | 특징 | 대표 요소 |
|---|---|---|
| `block` | 한 줄을 차지하는 요소. 기본적으로 각 요소가 새로운 줄에서 시작 | `<div>`, `<p>`, `<section>` |
| `inline` | 글자처럼 옆으로 이어지는 요소. 콘텐츠가 필요한 만큼의 공간만 사용 | `<span>`, `<a>` |
| `inline-block` | 옆으로 배치하면서 박스 크기도 조절 가능 | 버튼, 버튼처럼 보이는 링크 |

- `inline-block`은 버튼이나 버튼처럼 보이는 링크를 나란히 배치할 때 유용하다.

## 5. JavaScript map() 메서드

배열 안의 모든 요소 각각에 대하여 주어진 함수를 호출한 결과를 모아 **새로운 배열**을 반환하는 메서드. 원본 배열은 변하지 않고 유지된다.

- **반복 순회**: 배열의 첫 번째 요소부터 끝까지 순서대로 순회한다.
- **새로운 배열 생성**: 각 요소를 변환하거나 가공한 결과값들을 모아 새로운 배열을 리턴한다.
- **UI 컴포넌트 반복 렌더링**: 리액트 같은 프론트엔드 환경에서 데이터 목록(배열)을 화면에 동적으로 뿌려줄 때(JSX 안에서 마크업 컴포넌트로 변환할 때) 가장 널리 사용된다.

## 6. Next.js Link 컴포넌트

Next.js는 클라이언트 사이드 네비게이션을 지원하기 위해 기본 HTML의 `<a>` 태그 대신 `Link` 컴포넌트를 제공한다.

- **화면 깜빡임 없음 (전체 새로고침 방지)**: 일반 `<a>` 태그는 페이지를 이동할 때마다 브라우저가 HTML을 통째로 다시 불러와 화면이 깜빡이지만, `Link` 컴포넌트는 자바스크립트를 이용해 필요한 페이지 데이터만 비동기로 불러와 렌더링하므로 부드럽게 이동한다.
- **백그라운드 프리페칭**: 뷰포트(사용자의 눈에 보이는 화면 영역)에 `Link` 컴포넌트가 들어오면, Next.js가 해당 페이지의 코드를 미리 백그라운드에서 다운로드해 둔다. 덕분에 사용자가 링크를 클릭했을 때 지연 없이 즉시 페이지가 전환된다.
