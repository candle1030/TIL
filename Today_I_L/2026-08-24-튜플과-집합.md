# 튜플과 집합

**날짜:** 2026-08-24 (월) 오후

---

## 1. 튜플과 집합, 합/교/차집합 개요

`tuple`, `set`, packing/unpacking, 합집합·교집합·차집합을 다룬다.

## 2. 튜플(tuple)

- 순서가 있고, 중복 가능하다.
- 직접 수정은 불가능하다 (변경할 수 없다).

## 3. 집합(set)

- 순서가 없고, 중복이 제거된다.
- 집합 연산이 가능하다.

```python
{1, 2, 2, 3}  # -> {1, 2, 3}  (중복 제거)
```

| 연산 | 의미 |
|---|---|
| `A \| B` | 두 집합의 모든 고유한 값 (합집합) |
| `A & B` | 두 집합에 공통으로 있는 값 (교집합) |
| `A - B` | A에만 있고 B에는 없는 값 (차집합) |

## 4. 리스트 vs 튜플 vs 집합, 무엇을 쓸까

리스트를 쓸지 판단하는 기준:
- 값의 순서가 중요한가?
- 만든 뒤 값을 수정할 것인가?
- 같은 값의 중복을 허용할 것인가?

표기: 리스트 `[ ]`, 튜플 `( )` — 튜플은 값이 하나만 있어도 뒤에 `,`가 들어가야 한다.

```python
one_value = (10,)
not_tuple = (10)
print(type(one_value))   # <class 'tuple'>
print(type(not_tuple))   # <class 'int'>  (그냥 괄호로 묶인 숫자)
```

- 튜플도 인덱싱과 슬라이싱이 가능하다.
- 튜플을 직접 수정하면 코드 오류가 발생한다.

| | 리스트 | 튜플 | 집합 |
|---|---|---|---|
| 순서가 중요한가? | O | O | 순서에 의존하지 않음 |
