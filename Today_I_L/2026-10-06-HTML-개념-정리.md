# HTML은 무엇인가?    
HTML은 HyperText Markup Language의 약자이다.
HTML의 핵심 역할은 웹 문서의 구조와 의미를 정의하는 것.
---
    HTML = 구조

    CSS = 표현

    JavaScript = 동작
---
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>문서 제목</title>
</head>
<body>
    <h1>화면에 보이는 제목</h1>
    <p>화면에 보이는 본문입니다.</p>
</body>
</html>

---

    <!DOCTYPE html>
    이 문서가 HTML5 문서임을 브라우저에 알려줍니다.
---
    <html>
    HTML 문서 전체를 감싸는 최상위 요소입니다.
---
    <head>
    브라우저와 검색엔진이 참고할 문서 정보를 담습니다.
    대표적으로 다음을 포함합니다.
---
    • 문자 인코딩
    • 브라우저 탭 제목
    • CSS 연결 정보
    • 문서 메타데이터
---
    <body>
    사용자가 실제 화면에서 보는 콘텐츠가 들어갑니다.
