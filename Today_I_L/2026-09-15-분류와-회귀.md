# 이진 분류와 로지스틱 회귀, 소프트맥스 정리

**날짜:** 2026-09-15 (화)

---

## 1. 이진 분류와 로지스틱 회귀

- **이진 분류(Binary Classification)**: 데이터를 두 개의 범주 중 하나로 나누는 문제. (예: 스팸 메일 vs 정상 메일, 합격 vs 불합격)
- **로지스틱 회귀**: 이름은 '회귀'이지만 실제로는 분류를 수행하는 알고리즘. 선형 회귀 결과값을 0과 1 사이의 확률값으로 변환해 준다.

## 2. 출력층 활성화 함수: 시그모이드(Sigmoid)

모델이 출력하는 연속적인 값을 0과 1 사이의 확률값으로 압축해 주는 활성화 함수.

- 이진 분류 문제에서는 두 개의 클래스 중 하나에 속할 확률(예: 스팸일 확률 85%)을 구해야 하므로 시그모이드 함수를 출력층에 사용한다.
- 3개 이상의 클래스를 분류하는 '다중 분류'에서는 주로 소프트맥스 함수를 사용한다.

## 3. 손실 함수: 이진 크로스 엔트로피(Binary Cross-Entropy, BCE)

모델의 예측값과 실제 정답 사이의 오차를 측정하는 함수. 이진 분류 모델을 학습할 때는 확률적 오차를 계산하는 데 최적화된 이진 크로스 엔트로피를 손실 함수로 사용한다.

## 4. 소프트맥스(Softmax)

딥러닝에서 여러 개의 클래스 중 하나로 분류하는 다중 분류 문제의 출력층에서 주로 사용하는 활성화 함수. 오차를 계산할 때는 범주형 크로스 엔트로피를 사용한다.

**주요 역할**

- 모델이 계산한 각 클래스별 점수들을 0과 1 사이의 확률값으로 변환해 준다.
- 변환된 모든 확률의 총합은 항상 정확히 1이 되도록 만들어 준다.

**작동 방식 예시**

사진을 보고 고양이, 강아지, 토끼 중 하나를 맞추는 다중 분류 모델이 있다고 가정하면:

```
모델이 출력한 원시 점수:     [2.0, 1.0, 0.1]
소프트맥스 함수 적용 후:     [약 0.65, 약 0.24, 약 0.11]  (총합 1)
```

이 결과는 모델이 "65% 확률로 고양이, 24% 확률로 강아지, 11% 확률로 토끼"라고 판단했음을 의미하며, 가장 확률이 높은 고양이를 최종 정답으로 선택하게 된다.

## 5. 정답 레이블의 표현 방식

- **원-핫 인코딩**: 3개의 클래스가 있을 때 정답을 `[1, 0, 0]`, `[0, 1, 0]`, `[0, 0, 1]`처럼 배열 형태로 표현하는 방식.
- **정수형 레이블**: 클래스를 늘어놓지 않고 0, 1, 2 같은 하나의 정수로 표현하는 방식. 데이터가 많을 때 메모리를 훨씬 아낄 수 있다.

**스파스 범주형 크로스 엔트로피**

앞서 다중 분류에서 쓰인다고 배운 '범주형 크로스 엔트로피'는 정답이 원-핫 인코딩되어 있을 때 사용한다. 하지만 정답이 원-핫 인코딩이 아니라 정수형으로 되어 있을 때는, 변환 과정을 거치지 않고 정수 그대로 오차를 계산할 수 있는 **스파스 범주형 크로스 엔트로피**를 사용한다. 이름 앞의 '스파스'는 정수형 레이블을 효율적으로 처리한다는 의미를 담고 있다.

## 6. 다중공선성

머신러닝이나 통계 분석(특히 선형 회귀)에서 서로 독립적이어야 할 입력 변수들 간에 강한 상관관계가 나타나는 현상. 변수들끼리 너무 닮아 있거나 서로를 완벽하게 유추할 수 있어서, 모델이 올바른 학습(가중치 계산)을 하지 못하고 혼란에 빠지는 현상이다.
