# 객체지향 기초 개념과 SQL 정렬·중복 제거 (ORDER BY, DISTINCT)

**날짜:** 2026-09-07 (월)

---

## 1. 객체지향의 기본 용어

- **메서드**: 어떤 객체가 수행할 수 있는 동작(기능이나 행위)을 코드로 구현한 것.
  함수와의 차이는, 프로그램 전체에서 독립적으로 존재하는 함수와 달리 메서드는 특정 클래스나 객체 내부에 소속되어 있다는 점이다.
  예를 들어 '자동차'라는 객체가 있다면 전진(), 정지()처럼 동작 하나하나가 메서드가 된다.
- **클래스(Class)**: 객체를 만들기 위한 설계도나 틀. 데이터와 이를 처리할 메서드들이 함께 정의되어 있다.
- **객체/인스턴스(Object / Instance)**: 클래스라는 설계도를 바탕으로 실제로 메모리에 만들어진 실체.
  (붕어빵 틀이 클래스라면, 구워져 나온 개별 붕어빵들은 객체다.)
- **필드/속성(Field / Attribute)**: 객체가 가지고 있는 데이터나 상태를 저장하는 변수. 메서드가 '행동'이라면 필드는 '특징이나 값'에 해당한다.
- **생성자(Constructor)**: 클래스로부터 객체가 처음 생성될 때 자동으로 호출되어 필드를 초기화하거나 기본 설정을 하는 특수한 메서드.
- **상속(Inheritance)**: 이미 만들어진 클래스의 속성과 메서드를 다른 클래스가 물려받아 그대로 사용하거나 확장할 수 있게 해주는 기능.

## 2. ORDER BY로 정렬하기

`ORDER BY`는 SQL에서 조회 결과(ResultSet)를 특정 열의 값을 기준으로 정렬할 때 사용하는 구문이다.

```sql
-- 기본 문법
SELECT column_name
FROM table_name
ORDER BY grade [ASC | DESC];

-- 오름차순 정렬
SELECT * FROM students ORDER BY grade ASC;

-- 내림차순 정렬
SELECT * FROM students ORDER BY grade DESC;

-- 다중 기준 정렬
SELECT * FROM students ORDER BY grade DESC, name ASC;
```

> 데이터베이스 종류에 따라 NULL 값이 오름차순 정렬 시 가장 먼저/나중에 나타나는 등 미세한 차이가 있을 수 있으므로, 정확한 처리가 필요할 때는 각 DBMS의 공식 문서를 참고한다.

## 3. DISTINCT로 중복 제거하기

`DISTINCT`는 조회 결과에서 중복된 행을 제거하고 유일한 값들만 출력할 때 사용하는 키워드다.

```sql
SELECT DISTINCT 컬럼명1, 컬럼명2
FROM 테이블명;

-- 다중 컬럼 중복 제거
SELECT DISTINCT city, zipcode FROM users;

-- 중복을 제외한 개수 세기 (count와 함께 사용)
SELECT COUNT(DISTINCT category_id) AS unique_categories
FROM products;
```

- **지정된 모든 컬럼 기준**: 여러 컬럼을 지정하면 모든 컬럼의 값이 동일한 행들만 중복으로 판단해 제거한다. 하나의 컬럼만 다르더라도 다른 행으로 취급되어 출력된다.
- **NULL 값 처리**: NULL은 '알 수 없는 값'으로 취급되지만, DISTINCT는 NULL도 하나의 데이터로 인식하여 여러 개의 NULL 중 하나만 남기고 나머지는 제거한다.
- **성능 주의사항**: 중복 제거를 위해 내부적으로 정렬(sorting)이나 해싱(hashing) 작업을 거치므로, 데이터 양이 매우 많은 테이블에서 자주 사용하면 쿼리 성능이 저하될 수 있다.
