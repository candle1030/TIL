## 1. 딕셔너리 기본

`{}`는 딕셔너리를 의미한다.

```python
student = {
    "name": "민수",
    "age": 20,
    "score": 85
}

print(student["name"])      # 민수
student["score"] = 95
student["city"] = "서울"
```

- 대괄호 `[]` 안에 조회하거나 입력할 키를 적으면 그 값을 가져오거나 저장할 수 있다.
- 딕셔너리에 없는 키를 대괄호로 조회하면 `KeyError`가 발생한다.

## 2. get()으로 안전하게 조회하기

```python
student.get("city")
```

`get()`은 키가 없어도 오류 대신 `None`(또는 기본값)을 반환한다.

## 3. in으로 키 존재 여부 확인하기

```python
if "score" in student:
    print(student["score"])
```

`in`은 변수 안에 특정 키가 있는지 True/False로 확인한다.
