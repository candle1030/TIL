# 관계형 데이터베이스와 SQL 기초 (CRUD, DDL/DML/DCL) (chapter04)

**날짜:** 2026-09-07 (월) 오전

---

## 1. CRUD와 DML

- **C**reate, **R**ead, **U**pdate, **D**elete — 테이블 데이터를 처리하는 명령들로, 이를 DML(Data Manipulation Language)이라 한다.
- `CREATE TABLE`은 DDL(Data Definition Language)이다.

## 2. 조회 관련 키워드

- `column`: 컬럼(열)
- `RETURNING`: 실행 결과를 반환한다.
- `ASC`: 오름차순, `DESC`: 내림차순
- `WHERE`: 내가 보고 싶은 정보만 조회할 때 사용

**WHERE의 패턴 검색**

| 패턴 | 의미 |
|---|---|
| `'김%'` | 김으로 시작 |
| `'%민%'` | 중간에 민 포함 |
| `'%우'` | 우로 끝남 |
| `'김__'` | 김 뒤에 정확히 두 문자 |

- `LIMIT 3;`: 상위 3개만 조회

## 3. DDL / DML / DCL 정리

| 구분 | 대표 명령 | 역할 |
|---|---|---|
| DDL | `CREATE`, `ALTER`, `DROP` | 데이터베이스 구조를 정의·변경·삭제 |
| DML | `SELECT`, `INSERT`, `UPDATE`, `DELETE` | 데이터를 조작 |
| DCL | `GRANT`, `REVOKE` | 권한을 제어 |
