## 1. 데이터 분석 기본 흐름

범위 설정 → 필터링 → 파생 컬럼 생성 → 그룹화 → 집계 → 정렬 → 결과 검증

분석할 때는 먼저 "어떤 데이터를 볼 것인가?", "어떤 조건만 사용할 것인가?"를 정해야 한다. 같은 계산이라도 전체 주문인지 완료 주문인지에 따라 결과의 의미가 달라진다.

## 2. 여러 조건으로 필터링

- `&` → 그리고 (AND)
- `|` → 또는 (OR)
- `~` → 반대 (NOT)

```python
df[(df["quantity"] > 0) & (df["unit_price"] > 0)]
# 수량도 0보다 크고 단가도 0보다 큰 데이터

df["status"].isin(["completed", "shipped"])
# 상태가 completed 또는 shipped인지 확인
```

> 여러 조건을 사용할 때는 각 조건을 `()`로 감싸는 것이 안전하다.

**정렬**

```python
df.sort_values("line_total", ascending=False)
# ascending=True  → 오름차순
# ascending=False → 내림차순
```

"많이 팔린 제품"을 분석할 때는 판매 금액 기준인지 판매 수량 기준인지, 취소 주문을 포함하는지, 완료 주문만 보는지 등 분석 범위를 먼저 정해야 결과의 의미가 정확해진다.

## 3. 파생 컬럼 만들기

**파생 컬럼**이란 기존 컬럼을 이용해 새로 만든 컬럼이다.

- `line_total` = `quantity` × `unit_price` (주문 상세 한 줄의 금액)

```python
df["line_total"] = df["quantity"] * df["unit_price"]
```

> 계산식뿐 아니라 어떤 데이터 범위에 적용했는지도 함께 확인해야 한다.

## 4. 결과 검증

파생 컬럼을 만든 뒤에는 입력값과 결과가 맞는지, 금액 타입이 적절한지, 결측값이나 이상값(음수·0)이 있는지 확인한다.

```python
df.info()                     # 컬럼명, 데이터 타입, non-null 개수 확인
df["order_date"].isna().sum() # order_date의 결측값 개수
df["status"].value_counts()   # 컬럼 값별 빈도 확인
df.dropna()                   # 결측값이 있는 행 제거
```

- `info()`는 NULL 개수를 직접 보여주는 것이 아니라 non-null 개수를 보여준다.
- `dropna()`는 단순히 NULL을 확인하는 함수가 아니라, 기본적으로 결측값이 있는 행을 제거하는 함수다.
- **범주형 데이터**: 주문 상태, 성별, 카테고리처럼 특정한 값들로 이루어진 데이터.

## 5. 이상값(Outlier)

이상값이 있다고 바로 삭제하면 안 된다. 수량이 음수, 단가가 0원, 금액이 음수인 경우는 반품·환불·할인·테스트 데이터일 수도 있다. 업무 의미를 먼저 확인하고, 살릴 수 있는 데이터는 살린다.

## 6. groupby()와 agg()

**groupby**는 같은 기준의 데이터를 하나의 그룹으로 묶는 것으로, "결과 한 행의 기준"을 정한다. (카테고리별 → 한 행 = 카테고리 하나, 고객별 → 한 행 = 고객 하나, 월별 → 한 행 = 한 달)

```python
df.groupby("category")["line_total"].sum()
# 카테고리별 주문 금액 합계

df.groupby("category").agg(
    total_sales=("line_total", "sum"),
    avg_price=("unit_price", "mean"),
    order_count=("order_id", "nunique"),
)
```

**자주 사용하는 집계**

| 함수 | 의미 |
|---|---|
| `sum` | 합계 |
| `mean` | 평균 |
| `count` | 개수 |
| `nunique` | 중복을 제외한 고유 개수 |
| `min` / `max` | 최솟값 / 최댓값 |

> 같은 category groupby라도 전체 주문인지 완료 주문인지에 따라 결과의 의미가 달라지므로, 범위를 먼저 정한다.

## 7. 상세 행 수와 주문 건수, many_to_one

- **상세 행 수 ≠ 주문 건수**: 주문 1개에 상품 3개가 들어 있으면 주문 상세 행 수는 3, 주문 건수는 1이다.
- `count()`는 행·값의 개수를, `nunique()`는 중복을 제외한 고유한 값의 개수를 센다.

```python
df["order_id"].nunique()  # 실제 주문 건수
```

- **many_to_one**: 여러 개의 주문 상세가 하나의 주문에 연결되는 관계 (orders 1 ↔ order_items many). 주문과 주문 상세를 연결할 때는 어떤 컬럼을 기준으로 연결하는지 먼저 확인한다.

## 8. 날짜 데이터와 월별 분석

```python
df["order_date"] = pd.to_datetime(df["order_date"], errors="coerce")
# errors="coerce": 변환할 수 없는 값은 NaT로 처리

df["order_date"].isna().sum()
# 날짜 변환 실패 건수 + 기존 결측값 개수

df["order_month"] = df["order_date"].dt.to_period("M")
# 월별 분석에 사용할 파생 컬럼 (예: 2026-01, 2026-02, 2026-03)
```

## 9. products 연결하기 (merge)

주문 상세 데이터에 상품명·카테고리가 없다면 products를 연결한다.

```python
df = df.merge(products, on="product_id", how="left")
# 상품 ID를 기준으로 상품명, 카테고리 등을 붙임
```

- **many_to_one 확인**: 주문 상세 여러 행 → 상품 하나.
- 연결 전후의 행 수와 결측값을 반드시 확인한다.

## 10. 카테고리별 완료 주문 금액 (전체 흐름)

주문 상세 데이터 → 완료 주문만 필터링 → 상품 정보 연결 → `line_total` 계산 → category별 groupby → sum으로 합계 → 금액 내림차순 정렬

```python
completed = df[df["status"] == "completed"]
completed.groupby("category")["line_total"].sum()
```

## 11. describe()

수치형 데이터의 기초 통계 요약을 확인하는 함수.

```python
df["line_total"].describe()
```

| 값 | 의미 |
|---|---|
| `count` | 데이터 개수 |
| `mean` | 평균 |
| `std` | 표준편차 |
| `min` / `max` | 최솟값 / 최댓값 |
| `25%`, `50%`, `75%` | 1사분위수, 중앙값, 3사분위수 |

## 오늘의 핵심

1. 필터링 먼저, 정렬은 그다음.
2. `line_total = quantity × unit_price`.
3. `groupby`는 결과 한 행의 기준을 정한다.
4. 주문 건수는 상세 행 수가 아니라 `order_id.nunique()`로 확인한다.
5. 결과를 만들었으면 `info()`, `value_counts()`, `describe()`로 검증한다.
