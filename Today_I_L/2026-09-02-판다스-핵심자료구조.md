## 1. 판다스의 2가지 핵심 데이터 구조

- **Series**: 하나의 열로 이루어진 1차원 데이터.

```python
80
90
70
95
```

위와 같은 형태의 데이터를 pandas에서는 Series라는 형태로 다룰 수 있다.

- **DataFrame**: 열과 행으로 이루어진 2차원 데이터.

| 이름 | 점수 | 학년 |
|---|---|---|
| 철수 | 80 | 1 |
| 영희 | 90 | 2 |
| 민수 | 70 | 1 |

위처럼 여러 개의 항목을 표 형태로 가지고 있으면 DataFrame이다.

## 2. 가장 많이 쓰는 기본 작업 순서

```python
import pandas as pd

df = pd.read_csv('data.csv')   # 데이터 불러오기
```

## 3. 가장 많이 사용하는 핵심 명령어

```python
df.head()     # 데이터의 첫 행부터 5개만 보여줌
df.head(10)   # 괄호 안에 숫자를 넣으면 원하는 개수만큼 볼 수 있음
```
